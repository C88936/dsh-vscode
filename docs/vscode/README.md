## Authority

- Current code and tests in this repository are authoritative.
- The DSH source tree is the implementation base.
- MesCode remains a reference for VS Code integration and prior product
  decisions only. It is not a runtime dependency.

## First instruction to an implementer

Do not add a MesCode `Task`, `AgentLoop`, `ToolRegistry`, `ClineMessage`,
`session_events.jsonl`, DSH sidecar, DSH Web server or Simple Browser page.
Start by making the DSH fork build, then add `apps/vscode` as an in-process DSH
application.
